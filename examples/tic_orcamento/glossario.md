# Glossário operacional — corpus orçamento TIC PetroHorizonte

Apoio ao pacote POL-TIC-ORC-2025-02 / REO-2025-0142.

| Termo | Significado operacional neste corpus |
|---|---|
| **CGTIC** | Comitê de Governança de TIC; aprova Capex ≥ limiar e rebaselines (MUST-01, MUST-04). |
| **Change freeze orçamentário** | Últimos 10 dias corridos do trimestre; Opex > R$ 50 mil exige exceção do CFO (MUST-03). |
| **FinOps TIC** | Célula que arquiva spend semanal de cloud (MUST-05). |
| **NébulaOps Ltda.** | Fornecedor do aditivo Opex de suporte gerenciado no REO-2025-0142. |
| **OrbitLink Comunicações** | Fornecedor do Capex VSAT (PO-78441). |
| **PetroHorizonte S.A.** | Petrolífera fictícia controladora do orçamento de TIC. |
| **REO** | Registro de Evento Orçamentário de TIC. |
| **Unidade Offshore Delta (UOD)** | Unidade operacional fictícia gestora das linhas WBS-TIC-UOD-*. |
| **WBS-TIC-UOD-CLOUD-2025** | Linha Opex cloud com overrun no REO. |
| **WBS-TIC-UOD-NET-2025** | Linha Capex telecom (VSAT) aprovada pelo CGTIC. |
